## 技术可行性验证摘要

技术研究报告已验证的五个维度：

| 维度 | 核心结论 |
|:---|:---|
| 技术栈 | Next.js v16 + FastAPI + Neo4j (含向量索引) — 基于官方文档验证，完全可行 |
| 架构 | 模块化单体 + 分层知识模型，拆分路径清晰 |
| 集成 | GraphRAG 三层检索架构（图→语义→LLM），是当前行业标准模式 |
| 实现 | MVP 聚焦核心闭环（搜索→图谱→时间轴→AI问答） |
| 性能 | 缓存策略可综合节省 LLM 成本 60-80% |

**MVP 技术栈推荐：** Next.js + FastAPI + Neo4j（利用原生向量索引做图库 + 语义搜索），暂不引入独立 Milvus 以减少运维组件。

## LLM 成本估算详情

| 项目 | MVP 月费 |
|:---|:---:|
| 前端托管 (Vercel) | $0-20 |
| 后端主机 | $5-10 |
| 图数据库 (自托管 / Aura Free) | $0 |
| 向量数据库 (Neo4j 内置) | $0 |
| LLM API (主要开销) | $50-500 |
| Redis 缓存 (Upstash Free) | $0 |
| **总计** | **$55-530/月** |

**成本控制策略：** 语义相似缓存（30-50%节省） + 分层检索（图谱能答就不调LLM，20-30%） + 上下文裁剪（10-20%） + 模型选择（简单查询用小模型，30-50%）。

## 设计原则引用

来自脑暴的 8 条设计原则：

1. 渐进式信息密度
2. 即时响应 + 流式加载
3. 智能筛选 + 关联强度排序
4. 置信度标注 + 源头可追溯
5. 自动多粒度关键里程碑
6. 免费探索 + 高级功能付费
7. 多源交叉验证 + 源质量评级
8. 人物优先原则
