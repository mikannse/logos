# Logos：给你的好奇心装一张知识地图

你有没有过这种经历——

刷到一个陌生的名词，点开 Wikipedia，读了两段，发现里面引用了另一个你不懂的概念，点进去，再点进去……半小时后你开着 17 个标签页，大脑像一团乱麻，感觉自己「知道了很多」，但什么也串不起来。

我们太擅长收集碎片了。我们太不擅长看见全景。

**Logos 就是为这个做的。**

---

## 它是什么

Logos 是一个 AI 驱动的名词知识图谱与演化平台。你把一个名词扔进去，它自动给你三样东西：

1. **一张关系图谱**——这个词周围有哪些人、事、概念？它们怎么关联的？谁影响谁？
2. **一条演化时间轴**——这个词从哪来？经历了什么关键变化？下一步可能去哪？
3. **一个 AI 对话窗口**——对这堆关系问任何问题，不用自己翻 17 个标签页。

简单说：**Logos 是你个人专属的知识侦探。** 你丢线索，它帮你把拼图拼起来。

---

## 为什么是现在

如果你去翻知识图谱这个领域，会发现一件有意思的事：

- **基础设施很成熟**——Neo4j、Milvus、GraphRAG 都已经是经过验证的工业化组件
- **企业级产品很多**——Stardog、TigerGraph 们服务着大公司的数据团队
- **个人知识管理很火**——Obsidian、Notion、Heptabase 让普通人开始用图谱

**但没有一个产品把这三点串起来。** 没有产品能让你输入一个词，就自动得到一张带时间轴、能对话的知识地图。

市场上现有的选择：
- 你要么用 Obsidian **手动**做双链 —— 内容你自己写，图谱自己搭
- 你要么用 Diffbot **自动**爬数据 —— 但那是给开发者用的 API，没有可交互的界面
- 你要么用 Google **搜到**零散信息 —— 然后自己拼

Logos 要填的就是这个空白：**「自动构建 + 可视化探索 + AI 对话」**三合一的、面向普通人的知识探索工具。

（知识图谱市场正以 CAGR 18-32% 增长，2026 年约 19 亿美元，但面向普通消费者的象限 —— 空着。这不是巧合，这是机会。）

---

## 怎么玩

一个场景就够了：

你是一名记者。听说某科技公司最近收购了一家 AI 初创团队。你在 Logos 里搜那个初创公司的创始人名字。

**第一步：关系图谱展开。** 你看到他之前创办过另一家公司，那家公司被收购了——收购方就是今天的主角。图谱上两条线连起来，一目了然。

**第二步：时间轴拖回去。** 你把滑块拖到五年前，看到这位创始人的学术背景、第一次创业、产品上线、团队扩张、被收购——整个故事线按时间展开。这不只是信息，这是叙事。

**第三步：问 AI。** 「这位创始人和被收购公司 CTO 之前有没有合作过？」 AI 在图谱里跑了一圈，回来告诉你：「他们在 X 大学同一个实验室待过两年。」

你得到了一个独家选题的角度。而从搜索到发现，可能不到五分钟。

这就是 Logos 想做到的事情。

## 什么让它不一样

市面上不是没有知识图谱工具，但它们各有各的盲区：

| 产品 | 你能做什么 | 不能做什么 |
|:---|:---|---:|
| Wikipedia | 查一个词 | 没有图谱，没有时间轴演化，没有 AI |
| Obsidian | 手动做双链图谱 | 不自动构建，不爬外部数据 |
| Google KG / Diffbot | 自动结构化数据 | 无界面，无探索体验 |
| Neo4j / TigerGraph | 企业级图数据库 | 面向开发者，无法直接使用 |
| GraphRAG (微软) | 图谱+AI | 企业级工具，没有面向用户的 UI |

**Logos 的独特组合：**
- ✅ 自动构建（从公开数据源拉取 + LLM 提取）
- ✅ 关系图谱可视化（力导向图展示）
- ✅ 时间轴演化（知识是怎么演变的）
- ✅ AI 对话式探索（问它，不用自己翻）
- ✅ 面向普通用户（不需要写 Cypher 或 Python）

核心设计原则：**渐进式信息密度**——先给你全景，想看细节再深入，不一开始就砸你一脸数据。

## 路线图

```
🚀 Phase 1 —— 核心引擎（现在进行时）
   搜索名词 → 关系图谱 + 时间轴 + AI 问答
   技术栈：Next.js + FastAPI + Neo4j + D3.js + LLM API

🧠 Phase 2 —— 智能增强（6-18 月）
   AI 深度推理、多名词对比、多语言、个人知识库
   新增：Three.js 3D、Milvus 向量库、Celery 流水线

🌐 Phase 3 —— 生态化（18-36 月）
   3D 名词街景、知识社交网络、未来推演模式
   目标：成为一个不可替代的知识基础设施
```

## 现在在做什么

Phase 1 正在搭建中。技术上已经走通了全链路验证：
- Next.js + FastAPI + Neo4j（含向量索引）的组合经过官方文档验证，可行
- GraphRAG 三层检索架构（图遍历 → 语义搜索 → LLM 推理）是行业标准模式
- 月度成本可控（LLM API 是大头，约 $50-500/月，分层缓存可节省 60-80%）

**最高优先级：验证核心假设——「普通用户是否愿意用图谱化的方式探索知识？」**

最坏的情况是技术都做对了，但用户不喜欢这个交互范式。所以 Phase 1 一切都要快，要轻，要先让人用上。
