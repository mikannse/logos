# Patron Archetypes

四种目标用户角色，驱动功能优先级和体验设计。每个角色对应一条关键用户旅程（UJ）。

## 小明 — 普通好奇者

**场景：** 搜索一个不懂的名词。

**核心需求：** 快速理解 + 看到相关概念。

**完整路径：**
1. 在搜索框输入名词（如"涌现"）
2. 系统返回关系图谱（强关联：混沌理论、自组织、生命起源、群体智能；弱关联：AI、意识、经济现象）
3. 看到图谱的瞬间，对名词的语境有了直观感受
4. 时间轴展示：提出 → 生物学验证 → 跨学科扩散 → 当前热门前沿
5. 悬停感兴趣节点（如"自组织"），弹出摘要

**高潮：** 发现该名词和另一个概念存在强关联——这不是孤立概念。

**解决：** 理解名词的核心含义和位置，关闭页面。

**边界情况：** 输入非常冷门的词 → 系统提示数据有限，仅展示 Wikidata 已有数据。

*对应 UJ-1（见 PRD）*

## 林菀 — 科技记者

**场景：** 调查人物关系，写深度报道。

**核心需求：** 发现隐藏关联 + 关系网络可视化。

**完整路径：**
1. 在搜索框输入初创公司创始人的名字
2. 关系图谱展开，看到创始人之前创办过另一家公司——那家公司被收购了，收购方正是今天的主角
3. 图谱上两条线连起来，关联一目了然
4. 时间轴拖回五年前：创始人的学术背景 → 第一次创业 → 产品上线 → 团队扩张 → 被收购
5. 悬停 CTO 节点，看到他在 X 大学的学术背景——和创始人是同一所大学

**高潮：** 林记者在图谱上发现了一个关键关联——原来收购早有渊源，创始人和 CTO 曾共处同一学术环境。

**解决：** 导出图谱截图，写入报道框架。

*对应 UJ-2（见 PRD）*

---

## 王总 — 投资者 / 分析师

**场景：** 对某个技术赛道需要快速建立认知。

**核心需求：** 技术树 + 人物 / 公司分布 + 趋势推演。

**完整路径：**
1. 搜索"量子计算"
2. 图谱展示：核心概念（量子比特、叠加态、纠缠态）、关键人物（Shor、Grover）、关键公司（IBM、Google、IonQ）
3. 时间轴：1982 Feynman 提出 → 1994 Shor 算法 → 2000s 物理实现 → 2019 Google 量子霸权 → 2024 纠错突破
4. 点击一家创业公司节点，看到其融资时间线、核心技术路线

**高潮：** 发现中国和美国的技术路线选择了不同方向。

**解决：** 整理图谱信息作为投资备忘录。

*对应 UJ-3（见 PRD）*

---

## 阿花 — 独立内容创作者

**场景：** 撰写某个主题的深度长文。

**核心需求：** 演化脉络 + 资料素材积累。

**完整路径：**
1. 搜索"赛博朋克"
2. 图谱展示：核心概念（高科技低生活、控制论、反乌托邦）、代表作品（Neuromancer、银翼杀手、攻壳机动队）、关键主题（AI 觉醒、义体、巨型企业）
3. 时间轴：1980s 文学起源 → 1990s 电影爆发 → 2000s 游戏扩展 → 2010s 概念普及 → 2020s 现实交织
4. 点击 Neuromancer 节点，看到它如何影响后续作品

**高潮：** 发现一个有趣的隐藏关联——赛博朋克与日本泡沫经济的关系。

**解决：** 做了一系列截图和笔记，作为文章的结构框架。

*对应 UJ-4（见 PRD）*
