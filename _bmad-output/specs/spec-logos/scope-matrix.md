# Scope Matrix

## MVP In-Scope

- ✅ 搜索框输入名词 → 关系图谱 + 时间轴核心闭环
- ✅ 中英文双语搜索支持
- ✅ 人物优先入口和人物递归探索
- ✅ 多源交叉验证 + 置信度标注 + 来源追溯
- ✅ 渐进式信息密度展示（默认 50 节点，增量加载）
- ✅ 关联强度与类型可视化（边粗细 + 颜色编码）
- ✅ 时间轴-图谱动态联动
- ✅ SSE 图谱增量更新推送
- ✅ 响应式 Web 界面（桌面优先，移动端可用）

## Out of Scope for MVP

| 项目 | 推迟至 | 原因 |
|:---|:---:|:---|
| 用户注册 / 登录 | Phase 2 | 降低使用门槛优先于用户留存 |
| 个人知识库 | Phase 2 | 核心假设验证后再做留存功能 |
| AI 对话问答 | Phase 2 | BMad 已决策：LLM 仅用于数据管道 |
| 多名词对比 | Phase 2 | 复杂度高，不能影响核心闭环验证 |
| Three.js 3D 渲染 | Phase 2 | MVP 用 D3.js 足够 |
| 未来推演模式 | Phase 2 | 依赖 AI 深度推理能力 |
| Celery 异步流水线 | Phase 2 | MVP 用 FastAPI BackgroundTasks 即可 |
| Milvus 独立向量库 | Phase 2 | MVP 利用 Neo4j 内置向量索引 |
| 用户上传自有数据 | Phase 2 | 需要个人知识库功能作为前提 |
| 知识卡片分享 / 导出 | Phase 2 | 需要图谱导出能力 |
| 多语言全覆盖 | Phase 2 | MVP 聚焦中英文 |
| 利益关系分析 | Phase 3 | 需要积累足够的人物关系数据 |
| 社会化知识网络 | Phase 3 | 需要用户生态作为前提 |
