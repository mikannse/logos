# Design Principles

从脑暴、领域研究和 PRFAQ 确认的 8 条设计原则。这些原则驱动所有功能决策和体验设计。

1. **渐进式信息密度** — 先给全景，想看细节再深入。用户不一开始就被砸一脸数据。
2. **即时响应 + 流式加载** — 图谱骨架 500ms 内可见，后台逐步丰富。不要让用户等待。
3. **智能筛选 + 关联强度排序** — 最重要的关系优先展示。用户可通过关联类型、置信度、时间范围过滤。
4. **置信度标注 + 源头可追溯** — 每个事实都有根。用户永远知道这条信息从哪来、有多可靠。
5. **自动多粒度关键里程碑** — 5–10 个节点自动摘要。不需要用户手动标注时间线。
6. **免费探索 + 高级功能付费** — 基础搜索和图谱浏览免费。高级分析（AI 深度问答、多名词对比、个人知识库）按月订阅。
7. **多源交叉验证 + 源质量评级** — 同一事实从多个数据源比对。不一致的标低置信度并展示所有来源。
8. **人物优先原则** — 人物作为默认探索入口。人物节点在搜索排名和展示中优先。
